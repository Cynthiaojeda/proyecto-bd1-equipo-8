Desarrollo del tema
El centro veterinario desea llevar un control de sus clientes, mascotas, productos y atenciones medicas realizadas. De cada cliente se desea guardar, nombre, apellido, dirección, ciudad, teléfono. Un cliente puede tener una o varias mascotas registradas. De cada mascota se desea guardar nombre de la mascota, especie, raza, sexo, edad.
También se desea llevar un registro de los productos disponibles para la venta, especialmente de alimentos balanceados y accesorios. De cada alimento se desea guardar un código de alimento, marca, y cantidad disponible en kilogramos (kg). El sistema debe permitir poder controlar el stock de alimentos y poder conocer que marcas son las que tienen mayor y menor ventas.
El centro desea llevar un registro de las atenciones medicas realizadas. Cada vez que una mascota recibe una atención veterinaria, se genera un registro. De cada atención se desea guardar un numero de turno, fecha de ingreso, fecha de salida, tipo de atención (vacunación, revisión, internación) y observaciones.
Cada mascota corresponde a un único cliente. Un cliente puede no tener mascotas registradas o tener varias mascotas. Cada mascota puede no haber recibido ninguna atención o puede haber recibido varias a lo largo del tiempo.
El centro veterinario también desea registrar las compras realizadas por sus clientes. Cada compra deberá estar asociada a un único cliente y podrá incluir uno o varios productos. De cada compra se desea conocer el número de compra, fecha, tipo de cliente (mayorista o minorista) y monto total. Un cliente podrá no haber realizado ninguna compra o podrá realizar varias compras a lo largo del tiempo.
El sistema deberá permitir, además, que los clientes puedan solicitar turnos, realizar compras de alimentos y accesorios y consultar el historial de atenciones y compras. De esta manera, toda la información quedará registrada para facilitar futuras atenciones.
