Reglas de Negocio
RN.1 Cada cliente debe estar identificado mediante un Nro. de cliente único. 
RN.2 Un cliente puede tener una o varias mascotas registradas. 
RN.3 Cada mascota pertenece a un único cliente. 
RN.4 Una mascota puede no tener ninguna atención médica o puede tener varias atenciones a lo largo del tiempo. 
RN.5 Cada atención médica corresponde a una única mascota. 
RN.6 Toda atención médica debe registrar una fecha de ingreso. 
RN.7 Una atención médica puede tener una fecha de salida cuando corresponda. 
RN.8 Cada atención médica debe indicar el tipo de atención. 
RN.9 La veterinaria debe registrar los productos disponibles para la venta. 
RN.10 Cada alimento debe tener un código de alimento único. 
RN.11 De cada alimento se debe conocer su marca y la cantidad disponible en kilogramos. 
RN:12Cada compra debe estar asociada a un único cliente. 
RN.13 Un cliente puede no realizar ninguna compra o puede realizar varias compras a lo largo del tiempo. 
RN.14 Cada compra debe indicar si el cliente es mayorista o minorista. 
RN.15 Una compra debe incluir uno o varios productos. 
RN.16 El sistema debe permitir consultar las marcas de alimentos con mayor y menor cantidad de ventas. 
RN.17 Los clientes pueden solicitar turnos para recibir atención veterinaria. 
RN.18 Los clientes pueden realizar compras de alimentos y accesorios mediante el sistema. 
RN.19 Los clientes pueden consultar el historial de atenciones médicas y compras asociadas a sus mascotas. 
RN.20 Toda mascota debe estar relacionada con un cliente.
